# Prompt — Template Delta Engenharia

Crie um site institucional moderno, profissional e responsivo para uma empresa fictícia chamada **DELTA ENGENHARIA**, especializada em **manutenção predial**.

O site será utilizado como **template comercial para prospecção de pequenas empresas do setor de manutenção predial**. Portanto, a estrutura deve ser profissional, mas também modular e facilmente adaptável para outras empresas posteriormente.

## Objetivo do site

O objetivo principal é transmitir:

- profissionalismo;
- confiança;
- capacidade técnica;
- agilidade no atendimento;
- experiência em manutenção predial;
- capacidade de atender empresas, condomínios, comércios e indústrias;
- facilidade para solicitar orçamento.

A empresa deve parecer uma **microempresa especializada e competente**, e não uma grande construtora corporativa.

Evite exageros como "líder de mercado", "a maior empresa", "referência nacional" ou números inventados.

Não invente clientes, certificações, obras realizadas, anos de experiência ou estatísticas.

Utilize textos comerciais plausíveis e genéricos que possam posteriormente ser personalizados.

# IDENTIDADE VISUAL

Criar uma identidade visual relacionada a **engenharia, manutenção, infraestrutura e confiabilidade**.

## Estilo

- moderno;
- industrial;
- técnico;
- profissional;
- limpo;
- confiável;
- sofisticado sem parecer uma grande multinacional;
- bastante espaço em branco;
- boa hierarquia visual;
- elementos geométricos discretos;
- ícones relacionados a engenharia e manutenção.

## Paleta sugerida

Utilizar principalmente:

- azul escuro / navy para transmitir confiança;
- azul médio como cor de destaque;
- branco e cinza claro para fundos;
- cinza escuro para textos;
- pequenos detalhes em amarelo/laranja industrial para CTAs ou elementos de destaque.

A aparência deve lembrar empresas de engenharia, facilities e manutenção industrial.

## Tipografia

Utilizar uma fonte sans-serif moderna e profissional.

Priorizar:

- títulos fortes;
- textos fáceis de ler;
- contraste adequado;
- hierarquia visual clara.

# REQUISITOS DE DESIGN E UX

O site deve ser:

- totalmente responsivo;
- mobile-first;
- rápido;
- profissional;
- acessível;
- com excelente contraste;
- com botões claramente identificáveis;
- com CTAs distribuídos naturalmente pela página;
- sem excesso de animações;
- sem aparência de landing page genérica de IA.

Utilizar microinterações discretas:

- hover nos cards;
- animação suave nos botões;
- entrada sutil das seções;
- efeitos discretos nas imagens.

Não exagerar nas animações.

---

# DIREÇÃO VISUAL

A página deve transmitir a sensação de:

**"Uma empresa técnica, confiável e acessível que resolve problemas de manutenção para outras empresas."**

Evitar:

- visual excessivamente corporativo;
- excesso de azul;
- gradientes exagerados;
- excesso de elementos 3D;
- ilustrações infantis;
- excesso de texto;
- fotos de prédios genéricos como elemento principal;
- aparência de construtora residencial.

Priorizar imagens de:

- profissionais trabalhando;
- manutenção elétrica;
- ferramentas;
- quadros elétricos;
- instalações hidráulicas;
- equipamentos;
- ambientes comerciais;
- infraestrutura predial.

A composição deve funcionar bem como **template reutilizável para diferentes empresas locais**, permitindo substituir posteriormente:

1. Logo
2. Nome da empresa
3. Telefone
4. WhatsApp
5. E-mail
6. Cidade/região
7. Fotos
8. Cores
9. Serviços específicos
10. Segmentos atendidos

Criar uma página visualmente convincente mesmo sem utilizar informações específicas de uma empresa real.
